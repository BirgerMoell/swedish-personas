# NAISS

**National Academic Infrastructure for Supercomputing in Sweden.**

NAISS provides compute, storage and support for Swedish academic research. This organisation holds the models, datasets and tools that come out of our work on **training and deploying large language models, surrogate models and HPC-AI infrastructure**, so that they can be reused by researchers in Sweden and elsewhere.

## Datasets

- [Swedish Personas v3](https://huggingface.co/datasets/naiss-se/swedish-personas-v3): 100,000 synthetic Swedish people with SCB-conditioned structure, local names, model-written Swedish text and work profiles. CC BY 4.0.
- [Swedish Personas v2 (preview)](https://huggingface.co/datasets/naiss-se/swedish-personas-v2): the structured layer and a pilot, kept for reference.

## Code

The pipeline that builds the personas (SCB tables, name model, text generation, metrics) is open: [github.com/BirgerMoell/swedish-personas](https://github.com/BirgerMoell/swedish-personas). Code is MIT, data is CC BY 4.0.
